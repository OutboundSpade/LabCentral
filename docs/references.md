# Primary references

All sources were retrieved **2026-09-02**. Provider features remain target-discovered; these sources support design direction, not universal target guarantees.

| Proxmox architecture/API/network/storage | [Proxmox VE Administration Guide](https://pve.proxmox.com/pve-docs/pve-admin-guide.pdf) | PVE exposes REST through `pveproxy`; QEMU VMs, bridges/VLAN tags, clusters and storage capabilities are provider primitives. |

| Proxmox effective permissions and QEMU/task APIs | [Proxmox VE API Viewer](https://pve.proxmox.com/pve-docs/api-viewer/) | `/access/permissions` exposes effective privileges and their propagation state; child VMID/VLAN operations require applicable inherited grants. LabCentral calls it only after exact owned-resource checks and has the access process connect immediately. Retrieved 2026-09-04. |
