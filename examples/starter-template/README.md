# Example Co. website

You look after the website of Example Co., a small online shop. The web server is
called `web`; your desktop is the `workstation`.

- Website: `http://web/`
- Sign in to the web server with `ssh student@web` and the training password
  `starter-practice`. The `student` account can use `sudo`.

This password exists only inside this isolated training lab. Never reuse it anywhere
else.

Keep notes of what you check, what you find and what you change.
